# Google Cloud Architecture Framework & SRE

Este directorio está dedicado a las **buenas prácticas, pilares de arquitectura y conceptos de Site Reliability Engineering (SRE)** en Google Cloud.

## Google Cloud Architecture Framework (Pilares)

Google Cloud propone un marco de trabajo de arquitectura (Architecture Framework) estructurado en los siguientes pilares (buenas prácticas):

1. **Diseño del Sistema (System Design):** Principios básicos, componentes de nube, zonas, regiones, arquitectura global.
2. **Excelencia Operativa (Operational Excellence):** Automatización, monitoreo, CI/CD, gestión de incidentes y cultura SRE.
3. **Seguridad, Privacidad y Cumplimiento (Security, Privacy, and Compliance):** Gestión de identidades, encriptación, seguridad de red y cumplimiento de normativas.
4. **Confiabilidad (Reliability):** Alta disponibilidad, recuperación ante desastres (DR), SLAs, SLOs, SLIs y tolerancia a fallos.
5. **Optimización de Costos (Cost Optimization):** Monitoreo de facturación, uso de descuentos (Sustained/Committed Use Discounts), redimensionamiento de recursos (rightsizing).
6. **Optimización del Rendimiento (Performance Optimization):** Autoescalado, caché, bases de datos eficientes, balanceo de carga.
